## 🎧 About Apollo

Apollo is a local-first, audiophile-grade music player built for Windows. It is designed for users who care about audio fidelity and want a modern, responsive interface without sacrificing control over their library. 

Unlike bloated, streaming-first platforms, Apollo respects your original masters. It focuses on **bit-perfect playback**, **studio-grade DSP**, and a **lightning-fast library**, all wrapped in a fluid, glassmorphism UI.

---

## ✨ Features

### 🎛️ Pure Audio Fidelity
*   **WASAPI Exclusive Mode**: Bypass the Windows mixer for bit-perfect, unaltered audio.
*   **Studio-Grade DSP**: A 10-band parametric Equalizer, Compressor, Limiter, Reverb, and Saturation—all adjustable in real-time with zero clicks.
*   **ReplayGain**: Automatically normalizes volume across your entire library.
*   **Gapless Playback & Crossfade**: Seamless transitions for continuous albums and playlists.

### 🌌 Next-Generation Visuals
*   **Real-Time Wave Visualizer**: A genuine FFT-driven water-wave visualizer that reacts to the actual audio data.
*   **Dynamic Liquid Glass UI**: A modern, frosted-glass interface that extracts dominant colors from your album art.
*   **Synced Lyrics**: Auto-fetches word-by-word synced lyrics with a smooth, cinematic scrolling view.
*   **Music Mode**: Collapse the app into a sleek, always-on-top floating control bar for minimal desktop footprint.

### 📚 Smart Library Management
*   **Instant Search**: A SQLite-backed database that handles 100,000+ tracks without lag.
*   **Auto-Sync**: Monitors your music folders; if you rename or delete a file in Windows, Apollo updates instantly.
*   **Favorites & Most Played**: Built-in tracking for your most-loved tracks and listening history.

### 🖥️ Native Windows Integration
*   **Media Keys & Overlay**: Full System Media Transport Controls (SMTC) support.
*   **Smart File Association**: Double-click any audio file to play it instantly. Apollo detects if it's already open and routes the song to the existing window.
